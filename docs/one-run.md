# 실행부터 요약까지 한 번에 점검

RefurbCheck 1.4.0은 공장 초기화 후 백업 앱·설정을 복원하기 전에 실행하는 흐름을 기준으로 합니다. 앱을 열면 저장된 설정에 따라 자료 확인과 검사를 시작하고, 자동 연결 조건을 충족하는 조치와 재확인까지 이어집니다. 한 화면에서 진행 상태를 볼 수 있으며 상세 근거는 필요할 때 확인합니다.

첫 화면의 제목은 **‘한 번에 점검’**입니다. **‘상세 검사 결과와 근거 보기’**로 근거를 펼치고, **‘진행 옵션·안내’**에서 자동 진행 설정을 확인합니다. 직접 바꿔야 하는 항목은 **‘직접 확인할 다음 항목’** 카드에서 해당 화면을 열 수 있습니다.

## 실제 진행 순서

| 순서 | 수행 내용 | 다음 단계로 진행하는 기준 |
|---|---|---|
| 1. 자료 확인 | 자동 확인 설정이 켜져 있고 Wi-Fi 등 기존 확인 조건이 맞으면 서명 ZIP을 받음 | 서명·크기·지문·순번·만료·구성 검사 후 적용하거나, 기존 자료를 유지하고 상태 표시 |
| 2. 검사 | 현재 프로필의 설치 앱, APK 파일·서명, 설치 출처, 관리자 역할, 활성 권한 조합, 관측 가능한 시스템 신호와 키 증명 확인 | 검사 완료 후 적격 삭제 대상과 수동 확인·미확인 항목 분리 |
| 3. 조치 연결 | 적격 일반 앱의 현재 파일·버전·경로·관리자 상태·자료를 다시 확인 | 조건을 모두 충족하고 앱이 전면에 있을 때 Android 삭제 승인창 열기 |
| 4. 결과 확인 | Android 승인창에서 돌아오면 현재 설치 상태 확인 | 실제 미발견, 여전히 존재, 확인 불가를 구분하고 다음 진행 또는 보류 결정 |
| 5. 최종 정리 | 필요한 최종 재검사와 이번 실행의 결과 요약 | 조치 결과·보류·수동 확인·미확인을 함께 표시 |

자동 연결할 삭제 대상이 없으면 최초 검사 결과로 정리합니다. 같은 결과를 얻기 위한 전체 재검사를 무조건 두 번 수행하지 않습니다. 설정 화면으로 이동한 경우에는 흐름이 중단되지 않았다면 복귀 후 다시 관측해 이전 신호가 남는지 확인합니다.

## 기본값과 저장된 설정

처음 설치한 앱은 초기화 직후 정책과 Wi-Fi 자동 자료 확인을 사용합니다. 사용자가 끈 자동 자료 확인·삭제 승인 연결 설정은 다음 실행이나 업데이트 설치에서 다시 켜지지 않습니다. v1.3.0에서 v1.4.0으로 업데이트해도 같은 앱 저장소의 설정과 자료를 사용합니다.

Wi-Fi가 없거나 자료 확인 간격 등 조건이 맞지 않으면 자료 확인을 건너뛰고 사용 가능한 기존 자료로 검사합니다. 다운로드 실패는 새 자료 적용 성공으로 표시하지 않습니다. 자료 만료, 비정상 시각, 저장 오류, 불완전한 검사처럼 삭제 근거를 신뢰할 수 없는 경우에는 자동 삭제 연결을 보류합니다. 인터넷 연결 실패가 곧 검사를 모두 중단한다는 뜻은 아니며, 기존 자료의 유효성은 별도로 평가합니다.

## 자동으로 연결할 수 있는 조치

일반 사용자 앱 중 현재 통합 참조의 정확 파일 지문 일치가 확인되고, APK 파일 집합과 검사 결과가 완전하며, 삭제 직전 다시 같은 설치 상태와 유효 자료로 검증된 대상만 Android 삭제 승인창으로 연결합니다. 관리자 상태나 파일 변경처럼 조치를 보류할 조건이 있으면 승인창을 열지 않습니다.

초기화 직후라는 사용 목적은 예상하지 않은 소프트웨어를 확인 대상으로 올리는 기준입니다. 다음 항목은 그 사실 하나만으로 자동 삭제 근거가 되지 않습니다.

- 사용자가 설치하지 않았다고 예상하는 앱, 비시스템 앱, 낯선 패키지 이름.
- 스토어 이름이나 설치 출처의 부재·변경.
- 접근성·문자·통화기록 등 권한의 조합.
- 관리자 또는 업무 프로필 관련 패키지 이름.

파일 지문이 일치한 경우에도 원자료의 분류를 유지합니다. 모니터링 도구 참조와 악성코드 참조는 같은 뜻이 아닙니다. 삭제 요청은 초기화 직후 사용 정책과 검증된 파일 근거에 따른 것이며, 해당 도구의 모든 설치가 불법이라는 판정이 아닙니다.

## 사용자가 직접 해야 하는 부분

**Android 삭제 승인은 필수입니다.** RefurbCheck는 일반 앱으로 동작하며 삭제 버튼을 대신 누르거나 시스템 승인을 우회하지 않습니다. 여러 적격 대상이 있으면 각 대상의 시스템 승인 절차가 필요할 수 있습니다.

관리자·접근성·알림 접근·VPN·프록시·사용자 인증서·개발자 설정 등은 관측된 결과에 맞는 설정 화면을 안내합니다. 실제 토글 변경이나 관리자 해제는 사용자가 해당 화면에서 수행합니다. 삼성 보안 위험 자동 차단, Play Protect, 삼성 기기 보호의 검사도 해당 서비스의 화면과 지원 범위에 따릅니다. 화면을 열기만 했다고 이 앱이 해당 서비스의 검사를 실행·완료했다고 기록하지 않습니다.

조직의 기기 관리 등록, 다른 프로필, 삼성 Knox 원격 판정, OS·부트로더·펌웨어 복구, 물리 부품 확인은 이 흐름만으로 해결할 수 없습니다. 이런 항목은 확인 필요 또는 미확인으로 남습니다.

## 중지·취소·화면 이동

**‘자동 점검 중단’**을 누르거나 Android 삭제를 취소하면 다음 삭제 요청을 계속 띄우지 않습니다. 삭제 전 재검증 중 중지를 눌렀다면 늦게 도착한 재검증 결과만으로 승인창을 열지 않습니다. 취소한 흐름을 정상 완료나 전체 해결로 표시하지 않습니다. 다시 진행하려면 **‘새 점검으로 다시 시작’**을 눌러 현재 상태를 새로 검사합니다.

화면 회전과 일시적인 화면 이동에서 같은 검사를 중복으로 시작하지 않습니다. 진행 중인 Android 승인이나 설정 화면에서 돌아오면 결과 확인으로 연결합니다. 앱이 전면에 없는 동안 새 삭제 승인창을 열지 않으며, 전면 복귀 때는 현재 파일을 다시 검증한 뒤 승인창을 엽니다.

이미 중단한 흐름은 설정 화면에서 돌아왔다는 이유로 자동 재검사를 시작하지 않습니다. 이미 열려 있던 삭제 화면에서 돌아온 경우에는 실제 앱 존재 여부를 확인할 수 있지만 다음 자동 조치를 시작하지 않습니다. 중지는 Android에서 이미 승인한 삭제를 되돌리는 기능이 아닙니다.

앱 프로세스가 종료되면 실행 중 작업이 영구적으로 이어진다고 보장하지 않습니다. 백그라운드 상주 서비스나 부팅 후 자동 삭제 서비스는 사용하지 않습니다. 다시 실행한 경우에는 현재 설치 상태를 새로 관측해야 합니다.

## 요약을 읽는 방법

요약은 이번 실행에서 관측한 결과를 구분해 보여 줍니다. 삭제 승인창을 연 횟수와 실제 미발견 확인 수는 다릅니다.

| 결과 | 뜻 | 뜻하지 않는 것 |
|---|---|---|
| 현재 프로필에서 앱 미발견 | 삭제 결과 조회 시 해당 앱을 현재 프로필 목록에서 찾지 못함 | 다른 사용자·보안 폴더까지 제거됨, 향후 재설치 불가 |
| 앱이 남아 있음·보류 | 취소·차단·변경·재설치 가능성 등이 있어 제거 완료로 셀 수 없음 | 확인 없이 제거 성공으로 처리 |
| 설정 신호 미재발견 | 재검사 가능한 범위에서 이전 관측 신호가 보이지 않음 | 전체 OS 또는 관리 등록이 복구됨 |
| 미확인 | 권한·기기 지원·오류·읽기 제한 등으로 충분히 검사하지 못함 | 문제가 없다는 판정 |
| 흐름 완료 | 이번 자동 진행과 필요한 결과 정리를 마침 | 공장 순정 인증, 모든 악성코드 부재, 모든 위험 해결 |

기본 자료는 2026-11-06 구성의 15,645개 참조이며 v1.4.0에서 참조 수를 늘리지 않았습니다. 최신 자료 여부와 자동 조치 가능 여부는 실행 때 적용된 서명 자료의 상태로 확인합니다. 일치하는 참조가 없더라도 신규 악성코드나 펌웨어 변조가 없다는 증명은 아닙니다.

상세 검사 범위는 [README](../README.md), 자료 검증 절차는 [검사 자료 갱신](catalog-updates.md), 앱 출처와 권한 해석은 [설치 정책](inventory-policy.md)을 확인하세요.
