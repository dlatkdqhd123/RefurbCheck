# RefurbCheck 1.2.0 최종 배포 APK: API26 실행 관측

2026-11-06, AOSP Android 8.0/API26 x86 소프트웨어 에뮬레이터에서 수행했습니다. 설치 파일 SHA-256은 `addf557694e94e499f4409b764ccc0780629f137e1e6494ce5eb357e6d51be8c`입니다.

## 확인한 동작

앱을 설치·실행하면 검사가 시작됐고 실제 결과 화면에 버전 1.2.0, 결과/앱/조치/안내·비교 탭, 켜진 초기화 직후 자동 삭제 확인 모드가 나타났습니다. 결과 JSON 저장 버튼으로 Android 문서 선택기를 열고 실제 파일을 저장한 뒤 회수해 내용을 검증했습니다.

실제 보고서는 84개 패키지, 84개 APK 전체, 31,188개 직접 내부 파일 대조를 기록했습니다. 자료는 ClamAV 13,764개, Échap 1,594개, ESET 131개, MVT 156개와 ClamAV 허용 규칙 996개가 실제 로드됐습니다. 이 정상 이미지에서 자료 일치는 0개 앱입니다. 검사 시간은 약 156.7초였습니다.

배포 앱 자신을 읽은 SHA-256이 설치 APK와 같았고 자신에게 적용한 카탈로그의 다이제스트도 `7f833feefcb3b3e74c72f396571f6f457bff5eb4ca9511f502db9e56a2e31421`과 같았습니다. 앱이 공개한 범위의 완료와 별개로 악성코드 부재 인증은 false로 유지됩니다.

직접 ZIP 검사 범위의 완료와 별도로 중첩 압축 파일 1개는 재귀 해제하지 않았다고 기록합니다. 바깥 바이트 대조와 안쪽 내용 해제·분석을 구분합니다. 실제 split APK는 이 이미지에 없었습니다.
