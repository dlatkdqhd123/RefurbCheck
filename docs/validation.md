# RefurbCheck 1.2.0 검증 기록

검증일: 2026-11-06. 개발 환경에서 수행한 검증이며 사용자의 실제 갤럭시 진단 결과가 아닙니다. 이전 버전 기록은 [1.1.0](validation-1.1.0.md)과 [1.0.0](validation-1.0.0.md)에 보존했습니다.

## 배포 APK

| 항목 | 값 |
|---|---|
| 패키지 / 앱 이름 | `io.github.refurbcheck` / 리퍼폰 점검 |
| 버전 | 1.2.0 / versionCode 3 |
| 최소 Android | 8.0 / API 26 |
| compile/target SDK | 35 |
| APK 크기 | 853,855 bytes |
| APK SHA-256 | `addf557694e94e499f4409b764ccc0780629f137e1e6494ce5eb357e6d51be8c` |
| 서명 인증서 SHA-256 | `31a3041c7933acb7cdafad342bb574f0726f6045ddf5ccf4d9fd3fc7f1f126ff` |

공식 Android SDK 35.0.0의 aapt2·Java 컴파일·D8·zipalign·apksigner 경로로 빌드했습니다. v1.0.0·v1.1.0과 같은 개인 릴리스 키로 서명했으며 APK v2/v3, 서명자 1명/RSA 3072, 정렬, 패키지/버전/SDK/실행 Activity를 확인했습니다. 빌드 검증 출력은 `release/apk-build-verification.txt`, 입력 파일 지문은 `release/source-file-sha256.json`입니다. 이 목록 자체가 외부에서 서명한 빌드 증명서는 아닙니다.

권한은 `QUERY_ALL_PACKAGES`, `ACCESS_NETWORK_STATE`, `REQUEST_DELETE_PACKAGES`입니다. INTERNET 권한·네이티브 백신 라이브러리·백그라운드 서비스·광고·분석 SDK·자동 업로드는 없습니다. 백신 자료는 독립 TSV로 포함하고 앱의 Java 코드가 조회합니다.

## 호스트 회귀 검사

| 영역 | 수행 결과 |
|---|---|
| 부팅·패치 판정 | 22 assertions, 실패 0 |
| DER·인증서·앱 바인딩·교차 비교·폐기 자료 | 323 assertions, 실패 0. 잘린 DER 및 malformed 입력 2,000개 포함 |
| 실제 APK 서명·해시·기존 IOC·읽기 제한 | 30 시나리오, 51 assertions, 실패 0 |
| JSON 입력·보고서·기준 비교 | 91 시나리오, 478 assertions, 실패 0 |
| 기존 삭제 자격·조치 후 판정 | 57 시나리오, 107 assertions, 실패 0 |
| 신규 다중 해시·자료 파서·ZIP·허용 목록·출처 결합 | 91 시나리오, 1,331 assertions, 실패 0 |
| 신규 악성·감시 파일 삭제 근거 및 재검증 규칙 | 59 시나리오, 321 assertions, 실패 0 |
| 합계 | **2,633 assertions, 실패 0** |

구조화 결과는 [host-verification-v1.2.json](host-verification-v1.2.json), 보존한 실행 출력은 `docs/test-logs-v1.2/`에 있습니다. 같은 시나리오의 재실행이나 다른 런타임에서 반복한 결과를 추가 고유 assertion으로 합산하지 않았습니다.

실제 1.2.0 배포 APK와 classes.dex 저장 데이터 1바이트를 바꾼 사본을 사용해 정상 서명 검증과 변경 후 실패를 확인했습니다. ZIP 검사에는 저장/Deflate, CRC, 파일 크기, 로컬/중앙 헤더, 데이터 디스크립터, 경로 중복·탈출, 중첩 압축 표시, 지원하지 않는 구조, 읽기 예산, 취소 및 1,000개의 변형/잘림 입력이 포함됩니다. 변형 입력 수는 위 assertion 집계에 이미 포함되어 있습니다.

새 삭제 규칙은 시스템 앱·자기 앱·변경된 파일·근거 APK의 불완전 검사·잘린 일치 목록·모순되거나 타입이 잘못된 근거를 거부하는지 확인합니다. 전체 APK와 내부 파일의 출처·정확한 크기·다이제스트·외부 APK SHA-256을 연결합니다. MD5/SHA-1 근거에는 정확한 크기를 요구하며 Échap 분류를 비동의 감시 확정으로 승격하지 않습니다.

기존 MVT의 전체 APK SHA-256 일치에는 기존 재검증 경로가 우선 적용됩니다. 30초/2 GiB 예산으로 현재 일치 APK를 다시 읽고 자료·버전·상태·경로 구성 변화를 확인합니다. 이 경로에는 새 경로의 ZIP 완료 요구나 관리자 사전 조회가 없으며 해당 삭제 제한은 Android가 처리합니다. 새 참조 경로는 45초/3 GiB에서 근거 APK의 ZIP·전체 해시·동일 내부 파일 근거와 관리자 상태까지 추가 확인합니다. 두 경로 모두 정확히 확인한 파일의 근거를 사용하고 Android 승인과 실제 제거 확인을 거칩니다. 기기 전체 검사가 완료돼야만 개별 파일의 강한 근거를 사용할 수 있다는 뜻은 아닙니다.

별도 읽기 전용 검토에서 실제 15,645개 자료와 996개 허용 규칙을 128 MiB JVM에서 로드했습니다. 정상 1.1.0 APK 전체/직접 내부 파일에서 일치 0건 및 지원 범위 완료를 확인했습니다. 실제 원본 읽기와 예산 계수의 일치도 확인했습니다. 검토에서 발견한 파일 길이 재관측 및 잘린 일치 목록의 완료 판정 문제를 고쳤고 주요 테스트를 다시 적용했습니다.

최종 검토 후 앱의 라이선스 설명과 조치 안내 두 표시 문장만 명확히 수정했습니다. 검사·제거·자료·권한·서명키는 같으며 나머지 46개 생산 입력은 동일합니다. [문구 변경 기록](display-wording-correction-v1.2.json)을 남겼고 최종 APK를 다시 빌드·서명 검증하고 실제 Android에서 재검사했습니다.

## 실제 Android 실행: 최종 배포 APK

API26 x86 AOSP 소프트웨어 에뮬레이터에 **위 SHA-256의 최종 APK**를 설치했습니다. 자동 검사, 기본 활성화된 초기화 직후 모드, 네 탭, 실제 Android 문서 선택기 저장, 내보낸 JSON과 자기 APK의 해시 일치 등 11개 통합 확인이 통과했습니다.

| 실제 보고서의 관측값 | 결과 |
|---|---|
| 보이는 패키지 / 전체 APK 대조 | 84개 / 84개 |
| 직접 내부 파일 검사 | 31,188개 |
| APK 및 직접 ZIP 범위 완료 | 84개 / 84개 |
| 건너뛴 직접 내부 파일 | 0개 |
| 별도 재귀 해제하지 않은 중첩 압축 파일 | 1개 |
| 참조 자료 일치 | 0개 앱 |
| 실제 로드한 자료 | 참조 서명 15,645개 + ClamAV 허용 규칙 996개 |
| 검사 시간 | 약 156.7초 — 해당 느린 소프트웨어 가상기기의 관측값 |
| 공장 원본·악성코드 부재·물리 하드웨어 인증 | 수행하지 않음 / false |

`complete=true`는 명시한 전체 APK 및 지원되는 직접 내부 파일 범위에 한정합니다. 중첩 압축 파일은 그 파일 자체의 바이트만 대조하고 안쪽을 재귀 해제하지 않습니다. 모든 내용의 검사나 악성코드 부재를 뜻하지 않습니다.

이 이미지에는 실제 설치 split APK가 없었습니다. 실제 Galaxy와 One UI, 분할 앱 설치의 전체 통합 동작까지 검증한 것으로 확대하지 않습니다. 자세한 기록은 [API26 설명](validation-api26-v1.2.md), [통합 관측 수치](production-api26-v1.2.json), [실제로 저장한 JSON](fixtures/api26-v1.2-report.json)에 있습니다.

## 삭제 자동 진행의 실행 검증

실제 악성코드 대신 무해한 APK와 별도 테스트용 카탈로그를 사용하는 검증 전용 앱으로 시험했습니다. 생산 APK에는 합성 지표나 검증 앱을 포함하지 않습니다. 실제 승인·취소·다음 대상 처리 결과와 한계는 [검증 전용 제거 시험](test-only-remediation-v1.2.md)을 확인하세요. 이 시험은 탐지율·오탐률 측정이 아닙니다.

## 자료 검증과 공급 범위

ClamAV 원본 main/daily CVD의 내장 서명을 공식 ClamAV 1.5.4 sigtool로 확인하고 헤더·선택 멤버의 해시·폐기 자료를 검사했습니다. 확인한 것은 기존 CVD의 RSA/MD5 내장 서명이며 새 분리 `.sign` 방식의 검증을 했다고 주장하지 않습니다. 정규화 자료를 실제 ClamAV에도 로드했습니다. 원문 변형·헤더 불일치가 변환 단계에서 거부되는지, 동일 입력에서 같은 TSV가 생성되는지 확인했습니다.

Android 참조 13,764개는 main 63(2025-12-16)의 선별한 파일 해시 자료입니다. daily 28175(2026-11-06)는 폐기·허용 자료에 반영했습니다. ESET 131개, Échap 1,594개, MVT 156개는 출처별로 유지합니다. 15,645는 참조 서명 개수이며 독립 악성 앱 수나 탐지 성능의 수치가 아닙니다. 자료별 라이선스, 선택 원문, 커밋, 해시와 변환 코드를 `data/antivirus/`에 포함합니다. 전체 libclamav·ESET 엔진이나 모든 ClamAV 서명 종류를 포함하지 않습니다.

## 검증하지 않은 영역과 제한

- 물리 Galaxy·One UI·삼성 Knox·TEE/StrongBox·부품, 최신 Galaxy에서의 최종 실행 결과는 확인하지 않았습니다. API26 AOSP 결과는 삼성 펌웨어를 대체하지 않습니다.
- 1.2.0의 API35 실행 검증은 수행하지 않았습니다. 과거 1.1.0의 API35 제한된 시작 관측은 [과거 기록](api35-validation.md)이며 이번 버전의 호환성 통과로 재사용하지 않습니다.
- 실제 악성코드 바이너리·감염 기기를 사용하지 않았으며 오탐률·미탐률·미지 악성코드 차단 성능을 산출하지 않았습니다.
- 앱 내부 데이터, 실행 중 동적 다운로드 코드, 다른 사용자 프로필, 커널·펌웨어·부품은 검사 범위 밖입니다. 변조 OS는 이 앱이 읽는 관측값도 속일 수 있습니다.
- 자료 자동 인터넷 갱신은 없습니다. 새 자료는 APK 업데이트로 받으며 30일 경과·자료 오류·시각 이상은 최신성 확인 필요로 표시합니다.
- apksig-android 4.4.0의 플랫폼 모델은 API33까지입니다. API34 이상에서 암호 연산이 성공해도 최종 플랫폼 판정은 `UNKNOWN_PLATFORM`입니다.
- 접근성·관리자·인증서·시스템 보안 옵션 변경은 일반 앱이 대신 승인할 수 없습니다. 새 참조 경로는 활성 관리자 상태를 사전에 보류하고, 기존 MVT 전체 파일 경로는 해당 삭제 제한을 Android 시스템에 맡깁니다. 재검증 불가 시에는 요청을 보류합니다. 승인했어도 정책에 따라 실제 제거가 차단될 수 있습니다.
- 삭제 직전 검증과 Android 승인 사이의 시간 간격은 원자적이지 않습니다. 승인 화면의 대상도 사용자가 확인해야 합니다. 제거 후 다른 프로필·잔존 코드·OS 전체 복구를 인증하지 않습니다.
- 외부 증명 서버·Play Integrity·Samsung Enhanced Attestation·제조사 전체 파티션 비교는 구현하지 않았습니다.
- Gradle assemble/lint와 GitHub Actions 실행 완료는 검증하지 않았습니다. 공식 SDK 직접 빌드 성공과 CI 구성 제공을 CI 통과로 표현하지 않습니다.

에뮬레이터 준비에서는 이전 AVD 잠금 파일을 확인 후 정리했습니다. 첫 후보 APK의 통합 검사 처음에는 시스템 UI 응답 없음이 나타났고 화면의 Wait로 한 번 복구한 뒤 검사를 완료했습니다. 최종 실행의 수집 로그에서도 RefurbCheck FATAL EXCEPTION/ANR 여부를 확인했습니다. 가상환경 사건과 앱 검사 결과를 구분합니다.

최종 저장 시험에서는 비동기 SAF 쓰기가 끝나기 전에 자동화가 파일을 가져와 최초 사본이 0바이트였습니다. 동일한 선택 파일을 읽기 전용으로 다시 가져와 333,284바이트의 완성 JSON을 확인했습니다. 검사·저장·삭제 버튼을 반복 실행하지 않고 기존 UI 증거와 실제 JSON에서 나머지 검증을 이어갔습니다. 앱 코드는 변경하지 않았으며 자동화의 읽기 대기를 보완했습니다. 이 사건은 통합 JSON의 `harnessNotes`에도 기록했습니다.

개인 서명키·암호, 전체 CVD·도구 컨테이너, 검증 전용 APK는 배포 소스에 넣지 않습니다. 가상기기 화면과 수치는 사용자의 휴대전화 검사 결과가 아닙니다.
