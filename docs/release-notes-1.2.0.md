# RefurbCheck 1.2.0 · 악성 파일 자동 검사와 초기화 직후 조치

공장 초기화 직후 갤럭시를 점검하는 흐름에 맞춰 검사 자료와 조치 자동화를 강화했습니다. Wi-Fi로 APK를 받은 뒤 설치·실행하면 검사가 시작됩니다. 앱 자체 검사는 오프라인이며 루트·PC·ADB·계정·API 키가 필요하지 않습니다.

## 변경 사항

- **악성·감시 파일 참조 15,645개**: ClamAV Android 13,764개, ESET 공개 Android 지표 131개, Échap Android 감시 앱 지표 1,594개, 기존 MVT 156개. ClamAV 허용 규칙 996개도 별도로 적용합니다.
- 실제 APK 전체와 직접 포함된 파일을 검사합니다. MD5/SHA-1/SHA-256, 정확한 파일 크기, ZIP CRC·구조·제한을 확인하고 출처와 일치 위치를 남깁니다. 지원하지 않는 구조·중첩 압축·시간/크기 한계는 표시합니다.
- **초기화 직후 자동 삭제 확인 모드를 기본 활성화**했습니다. 정확한 파일 지표가 일치한 일반 앱은 현재 파일·버전·자료를 다시 검사하고 Android 삭제 확인창을 자동으로 엽니다. 승인 후 제거를 확인하고 다음 대상으로 이어지며 끝나면 재검사합니다. 취소·확인 실패 시 진행을 멈춥니다.
- 시스템 앱·점검 앱 자신·불완전하거나 변경된 제거 근거는 자동 대상에서 제외하거나 보류합니다. 새 참조 경로는 관리자 상태도 사전 확인하며 모든 대상의 실제 삭제는 Android 정책 제한을 따릅니다. 앱 이름과 권한만으로 삭제하지 않고 감시 앱 참조를 비동의 감시의 증거로 바꾸지 않습니다.
- 기존 OS/루팅·APK 서명·키 증명·갤럭시 공식 설정 연결·보고서 기능을 유지합니다. 설정 화면 열림이나 APK 검사 완료를 기기 전체 복구 완료로 표시하지 않습니다.

## 설치와 사용

1. 공장 초기화 뒤 앱·설정 백업을 복원하기 전에 `RefurbCheck-1.2.0.apk`를 받습니다.
2. Android 설치 화면에서 승인하고 **리퍼폰 점검**을 실행합니다.
3. 검출 시 자동으로 나타나는 Android 삭제 확인창의 앱을 확인하고 삭제를 승인합니다. 취소하면 진행을 멈춥니다.
4. 설정에서 직접 바꿔야 하는 항목은 조치 화면을 이용하고 돌아와 재검사합니다.
