# 악성코드 자동 검사: 자료, 구현 범위, 조치

## 이번 개선의 범위

RefurbCheck 1.2 계열은 기존 156개 MVT SHA-256 대조에 더해 **ClamAV의 Android용 파일 해시 서명, ESET의 공개 Android 조사 지표, Echap의 선별한 감시 앱 지표**를 자동 검사에 사용한다. 실제 읽은 기본 APK·분할 APK와 각 APK의 직접적인 ZIP 구성 파일을 검사한다. 검사할 때마다 사용자가 파일 해시를 복사하거나 외부 웹사이트에 등록할 필요가 없다.

앱에 들어가는 것은 독립적으로 작성한 파일 읽기·해시 비교 코드와 선별한 공개 자료다. **ClamAV 전체 네이티브 엔진이나 ESET의 상용 엔진을 포함하지 않는다.** 일반적인 백신의 모든 탐지·차단·치료 기능을 제공한다고 해석하면 안 된다. 결과의 의미는 해당 검사 범위에서 관찰한 서명 일치와 미확인 상태다.

검사는 기기에서 이루어진다. 앱 자체는 인터넷 권한을 요청하지 않고, APK·사진·문서·설치 앱 목록을 서버로 보내지 않는다. 내장 자료는 배포 시점의 스냅샷이며 별도의 일일 백신 정의 자동 갱신 서비스는 아니다.

## 사용한 자료

다음 수는 **자료별 선택 행 수**다. 서로 겹치는 파일이나 여러 이름이 있을 수 있으므로 합계를 악성코드 종류 수·실제 감염 사례 수·탐지율로 해석하지 않는다. ClamAV, ESET·Echap, MVT는 앱 자산에서도 **출처와 라이선스를 유지한 별도 TSV 자료**로 보존하고 실행 중 함께 조회한다. 자료별 최종 정렬·중복 처리와 SHA-256은 앱 자산의 메타데이터와 `tools/build_malware_catalog.py`의 출력이 기준이다.

| 자료 | 선택 행 수 | 범위와 기준 | 별도 라이선스 |
|---|---:|---|---|
| ClamAV Android 해시 서명 | 13,764 | `Andr.`/`Android.` 플랫폼의 `.hdb`/`.hsb`. 정확한 파일 크기를 유지하고 폐기·허용·중복 및 Adware/Tool/Packed 분류를 처리 | GPL-2.0-only |
| ESET 공개 Android 조사 지표 | 131 | Android를 명시한 12개 조사 그룹의 SHA-256 파일 목록 | BSD-2-Clause |
| Echap 감시 앱 지표 | 1,594 | 패키지·서명·제품 분류가 일관되는 선별된 Android 샘플. Watchware·겹치는 분류·불명확한 행은 제외 | CC BY 4.0 |
| 기존 MVT 공개 지표 | 156 | BTMOB·EagleMsgSpy 관련 고유 SHA-256 지표 | MIT |

ESET 선정 그룹은 AridSpy, CallPhantom, EvilVideo, GhostChat, GravityRAT, GREF/BadBazaar, Kamran, NGate, PromptSpy, ProSpy/ToSpy, SpyLoan, VajraSpy다. ESET는 해당 저장소의 `samples.sha256`가 조사한 파일들의 해시 목록임을 설명하며 소스와 바이너리 재배포에 BSD 2-Clause 조건을 제시한다.[4]

Echap 자료에서 일치하면 **공개 감시 도구 목록의 해당 파일과 일치했다는 뜻**이다. 실제 사용자 동의, 설치 목적, 기기에서 수행한 행위나 범죄 여부를 앱이 알아낸다는 뜻은 아니다. 원저장소도 미탐 가능성과 불완전한 범위를 명시한다.[5] 공장 초기화 후 사용할 기기를 점검하는 흐름에서는 이 일치를 삭제 확인 대상으로 제시하되, 도구 분류와 근거를 표시하고 실제 삭제는 Android 확인창에서 승인하게 한다.

## ClamAV 자료의 검증과 변환

### 원본 서명 확인

공식 CVDUpdate 1.2.0을 설치하여 지원되는 다운로드 방식을 실행했으나, 작업 환경의 DNS TXT 요청이 네트워크 제한으로 실패했다. DNS 설정이나 제한을 바꾸지 않고 종료했다. 공개 재배포 미러 `mirror.sg.gs`에서 원본 CVD를 받아 **공식 `clamav/clamav` Docker 이미지의 sigtool 1.5.4**로 두 파일의 디지털 서명 검증 성공을 확인했다. OCI manifest·config 및 내려받은 도구 레이어의 SHA-256도 확인했다.

검증에 사용한 CVD 서명은 기존 **RSA/MD5 내부 CVD 서명**이다. 별도의 최신 `.sign` 파일을 검증했다고 표현하지 않는다. 원본 해시와 검증 로그는 `data/antivirus/clamav/`에 보존한다. 미러의 날짜나 파일명을 신뢰하는 것만으로 검증을 대신하지 않았다.

ClamAV 공식 문서는 CVD가 디지털 서명된 데이터 컨테이너임을 설명하고, 일반 다운로드 스크립트 대신 FreshClam·CVDUpdate를 사용하도록 안내한다.[1][2] 공식 컨테이너는 ClamAV 도구의 배포 출처를 확인하는 데 사용했으며 그 Linux 실행 파일을 Android 앱에 넣지 않았다.[3]

### 어떤 행을 포함했나

1. `.hdb`/`.hsb`에서 서명 이름의 플랫폼이 `Andr.` 또는 `Android.`인 행만 선택했다. Windows 서명 이름에 Android라는 단어가 포함된 경우는 해당하지 않는다.
2. 공식 파일 크기를 유지했다. 이 자료는 **13,764개 모두 정확한 바이트 수**를 갖는다. `0`을 임의로 모든 크기와 일치하도록 바꾸지 않는다.
3. Malware, Trojan, Dropper, Spyware, Ransomware, Downloader, Keylogger, Virus 분류를 선택했다. Adware 239개, Tool 67개, Packed 2개는 제외 기록에 보존했다. PUA 전용 형식인 `.hdu`·`.hsu`도 적용하지 않는다.
4. `.ign`·`.ign2`의 서명 폐기를 반영했다. 이번 입력의 `Andr.Malware.Android_0294-3`은 폐기되어 제외됐다. 선택 이름과 일치하는 폐기는 추가 MD5 조건이 있더라도 보수적으로 제외한다.
5. 공식 `.fp`·`.sfp`를 합쳐 **996개 파일 허용 규칙**을 보존했다. 같은 알고리즘의 허용 해시와 충돌하는 선택 규칙은 없었다. 실행 중 다른 알고리즘의 허용 해시가 일치할 수 있으므로 파일 검사 때도 허용 규칙을 확인한다.
6. 동일 알고리즘·해시·크기의 별칭 4개를 별도로 기록하고 하나만 남겼다.

ClamAV 결과를 무효화하는 파일 허용 규칙을 ESET·MVT·Echap의 다른 근거까지 지우는 범용 안전 인증으로 사용하지 않는다. 해시 형식과 파일 허용·서명 제외 방법은 공식 문서에 근거한다.[6][7]

원본의 서명된 내부 `.info`에 기록된 파일 크기·SHA-256을 확인하며, CVD 외부 헤더의 버전·시각 등도 서명된 내부 정보와 비교한다. 선정 원문, 전체 관련 허용·제외 목록, 변환기, 제외 사유, 결과 해시를 제공해 어떤 자료가 실제 앱에 들어갔는지 검토할 수 있게 했다.

## 실제 검사 방식

### APK 전체와 내부 구성 파일

설치된 패키지에서 현재 앱 권한으로 읽을 수 있는 기본 APK와 분할 APK를 조사한다. 전체 파일에서 MD5·SHA-1·SHA-256을 계산하고 해당 알고리즘의 자료와 비교한다. 크기 조건이 있는 서명은 **해시와 정확한 바이트 수가 모두 일치**해야 한다.

APK는 ZIP 컨테이너이므로 직접적인 ZIP 엔트리를 읽고 해시를 따로 비교한다. APK 포장이나 서명만 달라졌지만 내부에 알려진 동일 파일이 남아 있는 경우를 추가로 찾을 수 있다. 그러나 재귀적인 압축 해제, 암호화 해제, DEX 코드의 의미 분석, HTML 정규화, 네이티브 코드 실행, 원격 다운로드 코드의 분석은 하지 않는다. 파일 내용을 실행하지 않고 읽기와 해시 계산만 수행한다.

검사 전후의 파일·설치 정보가 달라졌거나 읽기에 실패하면 그 관찰을 확정 결과로 승격하지 않는다. 파일 수·시간·읽기량 등의 제한이나 사용자 취소로 중단한 경우에는 검사하지 못한 범위를 남긴다. 중단된 검사의 미탐 결과를 완료된 음성 결과로 표시하지 않는다. 세부 제한과 결과 필드는 실제 구현과 해당 버전의 검증 기록을 기준으로 한다.

### 결과의 의미

| 결과 | 해석 | 조치 방향 |
|---|---|---|
| 백신·조사기관 해시 자료 일치 | 실제 읽은 바이트가 선택된 공개 규칙과 일치함 | 출처·파일·분류를 표시하고 조건에 맞는 일반 앱은 삭제 확인 대상으로 제시 |
| 감시 도구 자료 일치 | 선별된 감시 도구 샘플과 같은 파일 | 감시 도구 분류를 명시하고 사용자에게 삭제 확인을 제공 |
| 선택된 자료와 일치하지 않음 | 완료한 범위에서 해당 자료의 일치를 찾지 못함 | 악성코드 없음 또는 순정 기기 인증으로 확대하지 않음 |
| 일부 파일 미검사·실패·중단 | 해당 범위의 판단 근거가 부족함 | 실패 이유·누락 범위를 표시하고 필요하면 재검사 |
| 자료 손상·형식 오류·출처 무결성 확인 실패 | 정상적인 목록 대조를 신뢰할 수 없음 | 백신 검사 성공으로 표시하지 않음 |

MD5는 이 자료에서 알려진 파일을 찾는 식별값으로 쓰인다. MD5 일치는 앱 공급자 인증이나 OS 무결성 증명을 의미하지 않는다. 해시가 바뀐 변종, 목록에 없는 파일, 암호화된 구성 요소, 다른 사용자 영역, 앱의 비공개 데이터, 실행 중 메모리·커널·펌웨어·물리적 하드웨어는 이 검사로 모두 확인할 수 없다.

## 탐지 이후 조치

검사가 완료되면 현재 보고서에 남은 실제 자료 일치 중에서 조치할 수 있는 앱을 모은다. **기본 조치 흐름은 사용자 확인을 거치는 삭제 요청**이다. 루트 권한이나 접근성 자동 클릭을 사용하지 않는다.

- 시스템 앱과 점검 앱 자신은 삭제 요청 대상에서 제외한다.
- 사용자에게 어떤 앱의 어떤 파일이 어떤 자료에 일치했는지 표시한다.
- 삭제 요청 직전에 현재 설치 버전·상태를 다시 확인하고, 대상 APK를 다시 읽어 일치 근거가 유지되는지 확인한다.
- 파일 변경·앱 업데이트·권한 부족·읽기 실패가 생기면 삭제 요청을 차단하고 이유를 표시한다.
- 조건이 유지되면 Android의 시스템 삭제 확인창을 연다. 앱 및 앱 데이터 삭제는 이 확인창에서 사용자가 승인해야 한다.
- 삭제 확인창에서 돌아온 뒤 현재 사용자 영역의 설치 상태를 확인한다. 자동 진행에서는 제거가 확인되면 다음 대상으로 이어지고 마지막에 전체 재검사한다. 취소·실패하면 자동 진행을 멈추고 재검사하며, 설정 화면 방문을 ‘해결됨’으로 바꾸지 않는다.

기존 MVT 전체 APK SHA-256 일치 경로는 30초/2 GiB 예산으로 일치 APK와 현재 자료·버전·파일 상태를 재확인하며, ZIP 검사 완료나 관리자 상태 사전 조회를 별도로 요구하지 않는다. 새 백신·감시 참조 경로는 45초/3 GiB 예산으로 근거 APK의 전체 해시·동일 ZIP 근거·현재 경로 집합·UID를 추가 확인하고 활성 관리자 또는 관리자 상태 확인 불가면 사전 보류한다. 두 경로 모두 최종 제거는 Android의 사용자 승인과 정책 제한을 따른다. 모든 패키지의 모든 파일이 검사됐다는 전제를 두지 않으며, 완전히 읽은 해당 파일의 정확 일치와 기기 전체 검사 완료를 구분한다.

재검사와 시스템 확인창 사이에는 패키지 상태가 바뀔 수 있는 작은 시간 간격이 남는다. 일반 앱이 다른 앱의 업데이트와 삭제를 완전히 원자적으로 묶을 수 있다는 주장은 하지 않는다. 삭제를 완료해도 OS·펌웨어·기기 관리자 정책 또는 다른 곳에 남은 구성 요소의 복구가 보장되지는 않는다.

내보낸 JSON 보고서를 불러오는 기능은 읽기·비교용이다. 가져온 보고서의 주장으로 삭제 목록을 만들거나 시스템 조치를 실행하지 않는다. 실제 조치는 현재 기기에서 수행한 최신 검사와 재확인 결과를 사용한다.

|---|---|---|
| ClamAV | 네이티브 검사 엔진, 다양한 파일·압축 형식, 여러 종류의 서명, 서명된 CVD | Android 파일 해시 일부, 파일 크기 조건, 관련 허용·제외 목록. 전체 엔진·논리 규칙·바이트코드는 포함하지 않음 |
| Hypatia / MaintainTeam 포크 | MD5·SHA-1·SHA-256와 Bloom filter를 이용한 Android 검사. 포크 문서도 Bloom 일치의 오탐 가능성을 설명 | 자료 출처와 모바일 검사 구성을 참고. 앱 코드나 Bloom DB를 그대로 포함하지 않음 |
| ESET 상용 제품 / 공개 IOC 저장소 | 상용 제품의 엔진과 별도로 연구 결과의 파일 지표를 BSD 라이선스로 공개 | Android 조사 지표만 사용. ESET 상용 백신의 탐지율·치료 능력을 주장하지 않음 |
| MVT 공개 지표 | 모바일 침해 조사에 사용하는 공개 지표 | 선정 SHA-256 지표 대조. 전체 포렌식 도구나 모든 조사 모듈을 실행하지 않음 |
| Echap | 스토커웨어·Watchware 조사 자료와 불완전한 범위에 대한 설명 | 분류와 근거를 보존한 선별된 감시 도구 해시 대조 |
| 갤럭시 앱 보호 / Google Play Protect | 별도 제품의 악성 앱 점검 기능 | 기존 조치 화면에서 실행·설정 확인 경로 제공. 그 제품의 내부 엔진이나 결과를 읽었다고 간주하지 않음 |

Hypatia 원본 저장소는 2024-12-23에 보관됐고 MaintainTeam 포크가 공개되어 있다.[8][9] 해당 포크의 Bloom 필터에 일치했다는 이유만으로 앱을 확정 악성으로 분류하거나 자동 삭제하는 구현은 채택하지 않았다.

## 검증 기록을 읽는 방법

데이터 변환 단계에서는 공식 sigtool로 원본 CVD를 검증하고, 변환 TSV를 실제 ClamAV 1.5.4에 읽혀 형식을 확인했다. 기존 RefurbCheck 1.1.0 APK를 그 제한된 자료로 검사했을 때 일치가 없었으며, 원본 CVD 바이트 변경·메타데이터 변경·동봉 원문 변경의 거부와 같은 TSV 재생성을 확인했다. 이 기록은 `data/antivirus/clamav/conversion-verification.json`에 있다.

이는 **새 Android 앱의 전체 검증, 악성코드 탐지율, 오탐률 또는 실제 갤럭시 동작 검증 결과가 아니다.** 새 버전의 호스트 테스트·Android 실행·조치 검증 여부는 `docs/validation.md` 및 해당 버전 검증 문서를 별도로 확인해야 한다. 이전 1.1.0에서 통과한 테스트를 새 구현에서 다시 실행한 결과로 대신하지 않는다. 실제 악성 샘플을 실행하는 실험은 하지 않았다.

## 라이선스와 출처 보존

앱의 독립 작성 코드와 사용하는 데이터의 라이선스를 각각 표시한다. ClamAV CVD에 들어 있던 GNU GPL 버전 2 원문을 보존하고 **GPL-2.0-only**로 취급한다. 원문에 없는 ‘or later’ 허용을 붙이지 않는다. 선정 원문과 변환 코드·변환 내역을 함께 배포한다. ESET BSD 2-Clause 고지, Echap CC BY 4.0 출처·변경 표시, MVT MIT 고지도 유지한다. ClamAV 자료를 다른 라이선스의 자료와 하나의 TSV로 합치지 않고 별도 원문·변환 자료·메타데이터로 보존한다.

독립 작성 앱 코드는 MIT로 제공하지만 **앱에 동봉된 모든 데이터와 구성 요소가 MIT라는 뜻은 아니다.** 각 자료의 라이선스와 제3자 고지를 따로 제공한다. ‘ClamAV 엔진 내장’, ‘ESET 백신 탑재’, ‘삼성 인증’ 같은 표현은 실제 구성과 다르므로 사용하지 않는다.
