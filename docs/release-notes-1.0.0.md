# RefurbCheck 1.0.0

Android 8.0 이상에서 실행되는 한국어 리퍼폰 선별 점검 앱입니다. APK를 설치하고 열면 자동으로 검사합니다.

- OS·부팅 자기 보고값, 루팅·후킹 흔적, 설치 앱·서명, 접근성·관리자·네트워크·CA 설정 확인
- 공식 Google 루트 두 개와 하드웨어 키 증명의 로컬 대조
- JSON 결과 저장 및 같은 모델의 참고 보고서 비교
- INTERNET 권한, 광고, 분석 SDK 없음

**공장 출고 동일성·악성코드 부재·물리적 하드웨어 무변조를 인증하지 않습니다.** 악성코드 정밀 검사 엔진, 최신 증명 키 폐기조회, 외부 증명 검증은 포함하지 않았고 항상 확인 불가로 표시합니다.

`RefurbCheck-1.0.0.apk`가 설치 파일입니다. 소스 코드 ZIP은 설치 파일이 아닙니다. SHA-256과 서명 인증서 지문을 함께 제공합니다. 실제 검증 범위는 저장소의 docs/validation.md를 확인하세요.
