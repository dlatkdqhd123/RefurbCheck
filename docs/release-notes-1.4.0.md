# RefurbCheck 1.4.0

갤럭시 리퍼폰에서 앱을 열면 **자료 확인 → 검사 → 가능한 조치 연결 → 실제 결과 재확인 → 요약**까지 이어지도록 실행 흐름을 정리했습니다. Android 8.0(API26) 이상에서 APK를 설치하고 실행합니다.

## 설치와 업데이트

v1.3.0과 같은 서명키를 사용합니다. v1.3.0을 제거하지 않고 v1.4.0 APK로 업데이트 설치할 수 있으며, 앱 전용 설정과 검사 자료를 유지합니다. 자동 자료 확인이나 자동 삭제 승인 연결을 꺼 둔 설정은 그대로 존중합니다.

앱 ID는 `io.github.refurbcheck`, versionCode는 `5`입니다. APK 서명 인증서 SHA-256은 `d02b8c5cbcde0ad3fbd3eb9e4c66e28094a27cf4f7a8472d309f84d825184ceb`입니다.

v1.2.0은 서명키가 달라 업데이트 설치가 불가능합니다. 필요한 JSON 보고서를 먼저 보관하고 사용자가 이전 앱을 제거한 뒤 새로 설치해야 합니다. 제거하면 이전 앱의 전용 자료·설정은 삭제됩니다. 초기화 후 처음 설치하는 기기는 APK를 바로 설치합니다.

## 이번 버전의 변경

- 첫 화면에서 현재 단계와 진행 상태, 이번 실행의 조치 결과를 확인할 수 있습니다. 검사 뒤 별도 탭에서 자동 흐름을 다시 시작할 필요를 줄였습니다.
- 저장된 설정과 Wi-Fi 조건에 따라 서명 자료를 확인한 뒤 검사를 이어갑니다. 갱신을 건너뛰거나 실패했는지도 표시하며, 유효 자료가 없을 때 삭제 자동 연결을 보류하는 기존 조건을 유지합니다.
- 현재 유효 자료의 정확 파일 지문과 충분한 검사 근거가 있는 일반 앱은 삭제 직전 다시 검사하고 Android 승인창을 순서대로 연결합니다. 승인창을 열었다는 사실은 제거 성공으로 세지 않습니다.
- Android 창에서 돌아오면 현재 프로필의 설치 상태를 확인합니다. 실제로 앱을 찾지 못한 경우만 해당 결과로 집계하며, 취소·실패·앱 변경·관측 제한은 보류 또는 미확인으로 남깁니다.
- 필요한 조치 뒤 최종 재검사를 연결합니다. 조치 대상이 없으면 최초 검사 결과로 정리해 불필요한 전체 재검사를 반복하지 않습니다.
- 중지·삭제 취소 뒤 다음 승인창을 자동으로 계속 띄우지 않습니다. 화면 회전과 복귀에서 중복 실행을 막고, 앱이 전면에 없을 때 새 삭제 승인창을 열지 않습니다.
- 직접 바꿔야 하는 설정은 같은 흐름에서 안내합니다. 설정 화면을 열거나 돌아왔다는 이유만으로 위험이 해결됐다고 표시하지 않습니다.

‘한 번에’는 사용자가 검사·조치·재확인을 따로 시작할 필요를 줄였다는 뜻입니다. 앱 삭제에 필요한 Android 사용자 승인이나 관리자·접근성·보안 설정의 직접 확인은 남습니다. 루트 권한이나 접근성 자동 클릭으로 시스템 승인을 우회하지 않습니다.

## 검사 자료와 보안 경계

기본 참조는 기존 15,645개이며 구성일은 2026-11-06입니다. 이번 버전에서 신규 악성코드 참조가 추가됐다는 의미가 아닙니다. 새 자료는 게시자가 수집·검토·서명한 뒤 기존 업데이트 채널로 배포해야 적용됩니다. 서명·크기·지문·순번·만료·출처·자료 구성 검증 조건을 완화하지 않았습니다.

기존 파일 지문 검사, 설치 출처·관리 역할·활성 권한 조합, APK 서명 검증, 하드웨어 키 증명을 유지합니다. 원자료의 악성코드 참조와 모니터링 도구 참조 분류도 유지합니다. 단순 패키지 이름, 권한 조합, 초기화 후 비시스템 앱이라는 사실만으로 자동 삭제하지 않습니다.

검사 자료 다운로드 외에 APK·앱 목록·보고서·기기 식별자를 업로드하지 않습니다. 광고·분석 SDK·백그라운드 상주 서비스는 없습니다. 고정 GitHub 자료 서버는 접속 IP 등 일반 연결 정보를 볼 수 있습니다.

## 배포 검증

공개 릴리스 워크플로는 검토한 APK·소스 입력·서명 인증서 지문, 호스트 회귀 테스트, Android API26와 API36의 실행 검사를 요구합니다. 새 실행 흐름의 상태 전이·중지·취소·재확인과 기존 검사 기능을 점검하며, 원본 v1.3.0 APK에서 원본 v1.4.0 APK로 업데이트 설치한 뒤 버전과 앱 시작을 확인합니다.

별도 실행 검사용 APK에는 배포 APK와 동일한 코드·리소스·자산을 보존하고 CI 임시 서명만 적용합니다. 배포 서명키는 GitHub Actions에 제공하지 않습니다. 최종 실행 결과는 [v1.4.0 Actions 기록](https://github.com/dlatkdqhd123/RefurbCheck/actions/workflows/release.yml?query=branch%3Arelease%2F1.4.0)에서 확인할 수 있습니다. 과거 버전의 통과 건수를 이번 버전의 결과로 사용하지 않습니다.

APK, 전체 소스 ZIP, APK SHA-256, 서명 인증서 지문, 입력 소스 지문, 서명 자료 ZIP을 첨부합니다. **APK만 설치 파일**입니다. 자료 ZIP은 앱의 서명 자료 가져오기 기능에서 사용할 수 있습니다.

## 남는 한계

이 앱은 공장 순정, 모든 악성코드 부재, 물리 부품 무변조를 인증하지 않습니다. 신규 변종·실행 중 내려받는 코드·다른 프로필·앱 전용 데이터는 검사 범위 밖이거나 관측이 제한됩니다. 전체 펌웨어 원본 비교, 삼성 Knox 원격 판정, 독립 키 증명 서버, YARA-X·ML 탐지·VPN 격리는 구현하지 않았습니다.

일반 앱 권한으로 시스템 앱을 무승인 제거하거나 관리 조직 등록을 강제 해제하거나 OS를 복구할 수 없습니다. API26·36 실행 검사는 모든 Galaxy One UI 실기기의 기능·성능·오탐 검증을 대신하지 않습니다. 미확인 항목은 요약에 남기며, 흐름 완료를 전체 안전 판정으로 바꾸지 않습니다.
