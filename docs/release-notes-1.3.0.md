# RefurbCheck 1.3.0

갤럭시 리퍼폰의 초기화 후 검사에 설치 출처·관리 권한·서명 이력과 서명된 검사 자료 갱신을 추가했습니다. Android 8.0(API26) 이상에서 APK를 설치하고 실행합니다.

## 설치 전에 확인

**이번 APK는 v1.2.0과 서명키가 다릅니다.** 이전 개인키를 복구하지 못해 새 키로 발행했습니다. 기존 v1.2.0 위에 업데이트 설치할 수 없습니다. 필요한 JSON 보고서를 저장한 뒤 사용자가 이전 앱을 삭제하고 새로 설치하세요. 초기화 후 처음 설치하는 기기는 바로 설치할 수 있습니다. 앱 ID는 `io.github.refurbcheck`, versionCode는4입니다.

## 주요 개선

- 앱 실행/재검사 때 Wi-Fi에서 최대6시간간격으로 검사 자료 확인. 수동 확인·서명 ZIP 가져오기 지원.
- RSA3072 서명, SHA-256, 크기, 버전 순번, 만료, 출처·자료 구성 검증과 원자 교체. 앱 목록·APK·보고서는 전송하지 않음.
- 설치 요청 앱의 서명, 설치 기록 앱, API33 패키지 출처, API34 업데이트 소유 앱, 현재 서명과 서명 이력 수집.
- 초기화 후 예상하지 않은 비시스템 앱과 실제 활성 관리자/DO/PO 상태 확인. Knox 패키지 이름만으로 관리 등록 판정하지 않음.
- 활성 접근성+설치 요청, 접근성+문자·통화기록, 관리자+문자·통화기록의3개 근거 조합을 확인 대상으로 표시. 악성 확정 또는 삭제 조건 아님.
- AOSP Android16 QPR2 APK 서명 검증 소스로 갱신. API26–36 모델·v3.1 회전·다중 서명·SDK 모호성 처리.
- API31+ 비고유 기기 속성 증명 요청, 제한적인 구형factory인증서 만료 호환. RKP만료·잘못된 서명·미래인증서는 허용하지 않음.
- 정확한 참조 일치 앱 삭제는 현재 유효 자료로 재확인한 뒤 Android 승인창에 연결. 기기 관리자·앱 변경·자료 오류·만료는 보류. 오래된 별도 MVT 조치 경로 제거.

처음 배포하는 서명 자료#1은 기존 검토된 참조15,645개(구성일2026-11-06)를 새 배포 방식으로 포장한 것입니다. 새 악성코드15,645개를 추가했다는 의미가 아닙니다. 새 참조는 게시자가 검토·서명하여 배포해야 적용됩니다.

## 검증과 범위

호스트 회귀 테스트, 서명·APK 입력 지문 검증을 수행했습니다. 공개 릴리스 게시 작업은 Android API26/API36의 별도 실행 검사 성공을 요구합니다. 실행 검사는 배포 APK의 DEX·리소스·자산을 그대로 유지한 CI 임시 서명 사본을 사용하며, 배포 서명 APK의 설치·시작도 별도로 확인합니다. 개인 서명키와 배포 키로 서명한 테스트 앱은 GitHub에 올리지 않습니다.

모든 Galaxy One UI 모델의 실기기 시험, 실제 악성코드 탐지율, 물리 부품 진위, 전체 펌웨어 원본 비교는 수행하지 않았습니다. YARA-X·ML·VPN격리·외부 키 증명 서버·삼성 Knox 원격 검증은 포함되지 않습니다. ‘파일이 일치하지 않음’은 ‘악성코드 없음’이 아닙니다. 삭제는 Android 사용자 승인이 필요하며 시스템 앱·관리 조직 강제 해제·펌웨어 자동 복구는 수행하지 않습니다.

APK와 source ZIP, APK SHA-256, 새 서명 인증서 지문, 입력 소스 지문, 첫 서명 자료 ZIP을 첨부합니다. 검사 자료 ZIP은 결과 탭의 ‘서명된 자료 파일 가져오기’로 선택할 수 있습니다. APK/source/자료 ZIP 중 APK만 앱 설치 파일입니다.
