# RefurbCheck 1.1.0 · 갤럭시 검사와 조치

- 실제 base/split APK SHA-256 및 apksig 암호학적 서명 검사. API33 이후 플랫폼은 최종 서명 판정 UNKNOWN.
- 공개 MVT 파일 지표 156개 정확 대조, 출처·고정 해시·MIT 라이선스 포함.
- challenge/키/앱 패키지·버전·서명 바인딩, 7개 OS/부팅 교차 비교, 공식 폐기 목록 스냅샷.
- 갤럭시 Device Care·Members·자동 차단·소프트웨어 업데이트 조치 경로.
- 정확 지표 일치 사용자 앱만 삭제 직전 파일/버전을 재확인하고 Android 삭제 확인창 요청.
- 설정 복귀 후 재검사·조치 상태 기록. 화면 열림을 해결 완료로 처리하지 않음.
- 개발자 옵션/ADB의 제한된 0값을 안전·해결 완료로 처리하지 않음.
- 보고서 v2, 안정적인 실제 APK 해시 기준 비교, 가져오기 크기·UTF-8·깊이·형식 제한, 저장 사본.

루트·ADB·계정·API 키 없이 사용하는 무료 오프라인 앱입니다. 정상 권한 앱을 임의로 삭제하지 않습니다. 공장 출고 펌웨어 전체·물리 부품·미지 악성코드 무결성을 인증하지 않습니다. 실제 검증 범위와 남은 제한은 `docs/validation.md`, 상세 근거는 `docs/commercial-methodology-v1.1.md`와 `docs/attestation.md`를 확인하세요.

개인 릴리스 키는 v1.0.0과 동일합니다. 설치 후 외부 설치 허용을 해제하고 갤럭시 보안 위험 자동 차단을 다시 확인하세요.
